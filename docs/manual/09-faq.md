# FAQ

Hier finden Sie Antworten auf häufige Fragen zur Nutzung der SVWS-Konferenzübersicht.

## Kann ich die Anwendung auch ohne Internetverbindung nutzen?

Ja. Im Offline-Modus laden Sie die `enm.json.gz`-Datei manuell in den Browser. Die Darstellung und Auswertung erfolgt vollständig lokal.

## Werden die Daten an einen Server gesendet?

Nein. Die Anwendung ist so gestaltet, dass alle Daten im Browser verarbeitet werden. Es werden keine Schülerdaten oder Noten an Dritte weitergeleitet.

## Muss ich einen Server einrichten?

Nein. Sie können `index.html` direkt per Doppelklick öffnen oder einen einfachen statischen Webserver verwenden. Ein eigener Anwendungsserver ist nicht erforderlich.

## Welche Dateien kann ich laden?

Die Anwendung verarbeitet den SVWS-Export als `enm.json.gz`. Andere Dateitypen werden nicht unterstützt.

## Was mache ich, wenn die Datei nicht geladen wird?

Prüfen Sie, ob die Datei vollständig ist und vom SVWS-Server korrekt exportiert wurde. Achten Sie auf die Dateiendung `.json.gz` und verwenden Sie einen modernen Browser.

## Kann ich meine Änderungen speichern?

Alle Änderungen werden nur lokal im Browser gehalten. Verwenden Sie die Exportfunktion, um Ihre Ergebnisse als Datei zu sichern, bevor Sie die Seite schließen.

## Welche Browser werden empfohlen?

Aktuelle Versionen von Firefox, Chrome, Edge oder Safari sind am besten geeignet. Bei älteren Browsern kann die Verarbeitung großer Datenmengen problematisch sein.

## Was passiert, wenn ich den Browser schließe?

Beim Schließen des Browsers oder beim Neuladen der Seite gehen nicht gespeicherte Änderungen verloren. Exportieren Sie Ihre Daten vorher, wenn Sie sie später weiterverwenden möchten.

## Wie kann ich die App für mehrere Nutzer freigeben?

Die App selbst kann als statische Dateien auf einem zentralen Laufwerk oder einem Schulserver bereitgestellt werden. Jeder Nutzer lädt dann die Seite im Browser und lädt eigene Konferenzdaten.
